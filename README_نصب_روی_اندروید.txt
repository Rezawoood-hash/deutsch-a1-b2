راهنمای ۲ دقیقه‌ای نصب اپلیکیشن یکپارچه «آلمانی A1 تا B2» روی اندروید و ویندوز
================================================================================

این بسته یک وب‌اپلیکیشن پیشرفته (PWA) کامل و یکپارچه برای هر ۴ سطح A1 تا B2 است:
- index.html      (کل اپلیکیشن و دیتابیس کامل ۶٬۹۳۸ مدخل: A1=۱٬۸۳۱ | A2=۱٬۹۹۵ | B1=۱٬۹۲۱ | B2=۱٬۱۹۱)
- manifest.json   (تنظیمات نصب تمام‌صفحه، آیکون اختصاصی A1–B2 و میانبرهای لانچر اندروید)
- sw.js           (سرویس‌ورکر حافظهٔ آفلاین برای اجرای فوری بدون اینترنت)
- icon-192.png / icon-512.png / icon.svg (آیکون اختصاصی «A1–B2 DEUTSCH»)

ویژگی‌های کلیدی نسخهٔ یکپارچه (v3.4):
- نوار انتخاب سریع سطح (A1 | A2 | B1 | B2) ثابت در بالای صفحه با رنگ‌بندی اختصاصی هر سطح
- جست‌وجوی سراسری در هر ۶٬۸۹۷ واژهٔ یکتای ۴ سطح با برچسب رنگی سطح و پرش مستقیم به درس
- حفظ مستقل پیشرفت لایتنر هر سطح + پشتیبان‌گیری یکپارچهٔ ۴ سطح (سازگار با فایل‌های پشتیبان تکی قبلی)
- کش آفلاین مشترک صدای انسانی (de_all_audio_v1) بدون دانلود تکراری صداها بین سطوح

روش ۱: سریع‌ترین راه نصب روی گوشی بدون کدنویسی (Netlify Drop — کمتر از ۲ دقیقه)
---------------------------------------------------------------------------------
1. فایل ZIP را از حالت فشرده خارج کن تا پوشه‌ای با فایل‌های بالا داشته باشی.
2. وارد سایت https://app.netlify.com/drop شو.
3. کل پوشه را داخل صفحه بکش و رها کن تا لینک اختصاصی HTTPS بگیری.
4. لینک را در مرورگر Chrome روی گوشی اندروید باز کن.
5. دکمهٔ «📲» در نوار بالای اپ (یا منوی ⋮ کروم ← Install app / Add to Home screen) را بزن.
6. اپلیکیشن با آیکون اختصاصی «A1–B2 DEUTSCH» روی صفحهٔ اصلی نصب می‌شود و کاملاً آفلاین و تمام‌صفحه اجرا می‌شود.

روش ۲: میزبانی دائمی و رایگان روی GitHub Pages
----------------------------------------------
1. در GitHub یک مخزن (Repository) جدید بساز (مثلاً deutsch-a1-b2) و همهٔ فایل‌های داخل این بسته را آپلود کن.
2. از بخش Settings → Pages گزینهٔ Branch: main را فعال کن و لینک HTTPS ساخته‌شده را در کروم گوشی یا ویندوز نصب کن.

روش ۳: اجرای مستقیم و آفلاین روی ویندوز / اندروید بدون هاست
-----------------------------------------------------------
فایل index.html (یا فایل تک‌فایلی Deutsch_A1_B2_App_v3_4.html) را مستقیماً در کروم یا اج باز کن؛
همهٔ امکانات (درس‌ها، جست‌وجوی سراسری، لایتنر، پشتیبان‌گیری و کش صدا) بدون نیاز به اینترنت کار می‌کنند.
